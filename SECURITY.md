# Security policy

This public repository contains portfolio documentation only; the UtoAegis source code and operational security details remain in private repositories.

Do not post suspected vulnerabilities, sensitive deployment details, credentials, personal data, or malware in a public issue. Contact the repository owner privately through the [@Utopias187 GitHub profile](https://github.com/Utopias187) with a concise description and safe reproduction information.

Testing is authorized only on systems and files you own or have explicit permission to assess. The proprietary license remains controlling and this policy grants no permission to access, use, or redistribute private source code.
